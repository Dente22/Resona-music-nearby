# Uploads — файлы для репозитория

Положите сюда материалы, которые **нужно** закоммитить в git
(иконки, скриншоты, демо-треки небольшого размера, документы).

## Что сюда

- ассеты для README / релизов
- небольшие примеры (не вся музыкальная библиотека)
- файлы, которыми делитесь через репозиторий

## Что НЕ сюда

Личные данные приложения живут в **`userdata/`** (gitignore):

```
userdata/
  data/          # library.json, playlists, settings, embed-playback…
  music/         # импортированные треки
  covers/        # обложки
  app.log
```

`userdata/` не копируется во фронтенд и не переносится в репозиторий.
